# Rutas Viveres Emmanuel
Plataforma web para la optimización de rutas de distribución de Víveres Emmanuel.

## Tecnologías
* HTML5 / CSS3 (TailwindCSS)
* Vanilla JavaScript (MVC)
* Supabase (PostgreSQL)

## Cómo ejecutar el proyecto
1. Clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir el archivo `src/index.html` con la extensión **Live Server**.
4. Asegurarse de tener conexión a internet para cargar Tailwind y conectar con Supabase.
